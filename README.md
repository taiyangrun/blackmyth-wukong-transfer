# 黑神话实况转绘 (`blackmyth-wukong-transfer`) v1.0.0

把实拍照片一键转成《黑神话：悟空》游戏截图风格：东方神话山水、古刹石窟、云雾缭绕、紧箍咒与金箍棒，附可复用的转绘提示词模板。

Transform real-world reference photos into Black Myth: Wukong in-game screenshot prompts or generated images with maximum BMW rendering fidelity. Use when the user provides mountain, temple, stone forest, ancient building, misty landscape, forest, waterfall, or travel photos and asks for Black Myth Wukong screenshot transfer, photo-to-mythic-China prompt writing, image-to-image prompts, destined-one and staff elements, or reusable real-photo-to-BMW workflows.

## 文件结构

- `SKILL.md` —— skill 定义（含完整转绘提示词配方 / 工作流）
- `agents/openai.yaml` —— agent 配置
- `icon.png` —— skill 定制图标

## 使用方式

将本仓库作为 skill 包使用：把 `SKILL.md`、`agents/`、`icon.png` 放入你的 skill 目录即可。也已同步上架 [skillhub.cn](https://skillhub.cn) 与 ModelScope（魔搭社区），搜 `blackmyth-wukong-transfer` 即可找到。
